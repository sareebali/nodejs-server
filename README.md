## Basic Node.js Server
- Works with data in MOCK_DATA.json
- Endpoints:
    1. GET /users - HTML document render
    2. GET /api/users - List all users JSON
    3. GET /api/users/id - Get the user with id (for e.g. 1)
    4. POST /api/users - Create new user
    5. PATCH /api/users/id - Edit user with id
    6. DELETE /api/users/id - Delete the user with id
